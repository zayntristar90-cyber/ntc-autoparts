NTC Auto Parts - PWA (Vercel / any static host)
Upload every file in this folder to the ROOT of your site (index.html must be at the top level).
Vercel: vercel.com > Add New > Project > import the GitHub repo > Framework Preset "Other" > Deploy.
Or with CLI: npm i -g vercel, then run "vercel --prod" inside this folder.
Facebook / LinkedIn links: edit the SOC constant inside index.html.
